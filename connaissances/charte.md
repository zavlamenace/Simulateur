# Charte graphique — relevée sur billardsdefrance.fr (thème `billardsdefrance2026`)

Cette charte fait foi pour l'outil de devis et le PDF. Le configurateur (`configurateur-billard.html`) utilise une ancienne charte : **ne pas s'en inspirer**.

## Typographies
| Usage | Police | Détail |
|---|---|---|
| Titres (h1–h6) | **EB Garamond**, 700 | Interligne 1,2, couleur `#151515` |
| Texte et interface | **DM Sans**, 400 | Graisses 300 à 800 disponibles ; corps 1rem, interligne 1,5 |

Les deux polices sont sur Google Fonts, sous licence OFL : on peut les intégrer dans un PDF.

## Couleurs
| Rôle | Valeur | Usage sur le site |
|---|---|---|
| Encre / noir | `#151515` | Texte, titres, boutons sombres (couleur dominante) |
| Rouge de marque | `#b01c2e` | Boutons d'action, accents |
| Rouge survol | `#961827` / `#8d1625` | États actifs |
| Anthracite | `#3d4248` | Textes secondaires, barres |
| Crème | `#f6f3ee` | Fonds de sections, tunnel de commande |
| Sable clair | `#efe9e3` | Fonds, séparateurs |
| Sable | `#d9cfbf` | Texte sur fond sombre, filets |
| Blanc | `#ffffff` | Fond principal |

## Principes pour le PDF
- Épuré, qui va à l'essentiel ; beaucoup de blanc ; grille typographique stricte.
- Aucun dégradé, aucune ombre décorative, aucune icône gadget, aucun emoji.
- Le rouge est réservé à l'action « Je valide mon devis » et éventuellement à un filet.
- Les photos (billard détouré, détails) portent le message.
